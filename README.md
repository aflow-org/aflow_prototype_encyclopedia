# Aflow prototype encyclopedia - data collection

## Data Structure
- the data for each prototype is stored in a subfolder under `data` named after it's label
- structured information are available in `info.json`
- `base.bib` contains the citation to the first known report of the original structure
- `found_in.bib` contains the citation to the report that lead to the inclusion of this prototype into the dataset

## References
